# RDW Labz Website — Build Plan (approved scope)

## Overview
2-page playful-tech site for rdwlabz.com. RDW Labz is a dev team that builds software, games, mods and asset packs. Fully separate from any other company or site.
- Goal: one hub that says who we are, shows what we build, and gives a way to reach out.
- Audience: players, modders, asset-pack buyers + potential clients/collaborators.
- Decided: Home + Projects, footer email, playful tech, brand built from scratch, project links later.

## Sitemap
**Home:** hero + 2 pill CTAs → what we build (Software, Games, Mods, Asset packs) → featured projects → work with us → CTA band.
**Projects:** intro → filter chips (All, Software, Games, Mods, Asset packs) → project cards (image, name, one-liner, category, status, platforms, link or "Coming soon").
**Shared:** header (logo, Home, Projects, Contact pill), footer (mailto, © RDW Labz), 404.

## Phases and gates
1. Brand (3 logo concepts, 3 palettes, fonts) → gate: direction picked (agent picks, records why)
2. Design (studies, hero + project section, desktop/mobile)
3. Build (tokens, primitives, Home, Projects, motion)
4. Content + QA (copy placeholders, devices, Lighthouse, a11y)
5. Launch → gate: **Braden's go-live OK**. Agent does NOT deploy.
